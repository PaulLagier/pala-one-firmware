To upload books

On your Pala One, open Upload from the device menu.

The screen will show a link like http://pala-one.local — open it on any device that's on the same Wi-Fi network to upload books, apps, or a custom sleep image.

If pala-one.local doesn't load

Some networks don't resolve .local hostnames. Use the IP address shown underneath on the device's screen instead (e.g. http://192.168.1.42).
