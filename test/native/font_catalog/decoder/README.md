# Native font decoder fixture

Unmodified U8g2_for_Adafruit_GFX 1.8.0 decoder/header, the exact release pinned
in platformio.ini. Source: https://github.com/olikraus/U8g2_for_Adafruit_GFX
Original Oliver Kraus BSD license notices are retained in both files.
SHA256.json records the files from the PlatformIO 1.8.0 package. This fixture
lets offline host tests exercise the actual decoder; it is not device code.
When updating the firmware dependency, update this fixture and its hashes too.
