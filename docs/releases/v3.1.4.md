Pala One v3.1.4 improves idle-sleep and USB provisioning behavior while retaining all eleven languages and the existing partition layout.

- An idle USB host no longer prevents automatic sleep indefinitely. Actual USB traffic holds a five-minute setup window; queued bytes protect a request arriving just before the sleep gate. Wake a sleeping reader before starting setup.
- Automatic sleep preserves held buttons, pending click sequences and unpolled input edges. This also protects configured unlock sequences at the locked idle deadline.
- USB Wi-Fi association advances between input-loop iterations instead of waiting in a connection retry loop. It has a wrap-safe 30-second timeout; device/state queries remain available, and new credentials replace a pending attempt. Network scans are rejected while association is pending.
- Failed or cancelled connections do not replace saved credentials. Radio cleanup releases only provisioning-owned state and does not switch off an upload-owned access point. Credential byte lengths are checked before connection.

Choose V1.1 or V1.2 according to your PCB. EN/ES/FR specify the initial language only; every image contains all eleven languages. Release archives include English instructions, source provenance and SHA-256 checksums.

This update addresses verified software paths. General freeze, charging and router-compatibility reports remain open until their individual cause is established. Existing ordinary/V3 bookmark compatibility and rollback guidance still apply.
