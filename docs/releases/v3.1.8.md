Pala One v3.1.8 improves the screensaver editor and sharing workflow.

- Rotate source images clockwise in 90-degree steps. Fitting respects the rotated dimensions; repeating four times restores the original source without cumulative image loss.
- Open existing 3904-byte `.bin` screensavers directly in the editor. Invalid lengths are rejected, and stale asynchronous image loads cannot replace a newer selection.
- Download screensavers as standard BMP images from the main download button. A separate BIN link retains raw backups and direct slot uploads. BMP images can be reopened in the editor; browser-specific security policy is unchanged.
- Retain normal image imports, pan/zoom, threshold, inversion and destination selection. All eleven languages and the existing on-device bitmap format are preserved.

Both V1.1 and V1.2 builds retain the existing partition layout. EN/ES/FR specify the initial language only; every build includes all runtime languages.
