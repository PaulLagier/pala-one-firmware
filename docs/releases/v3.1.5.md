Pala One v3.1.5 adds optional reader controls while keeping the existing board variants, eleven runtime languages and partition layout.

- Change the reading progress bar between Full, Minimal and Hidden from browser settings. Its dedicated form preserves other preferences and the canonical reading position when page geometry changes.
- Hide the lock badge on the sleep screen without disabling the lock or changing the unlock gesture. The badge remains enabled by default.
- Assign an optional quadruple-click action in the custom button settings. It starts unassigned, and a Quad binding to Lock also works for unlocking. Legacy controls retain their existing gestures.
- Expose the optional controls through typed companion settings without changing the legacy hold-action mapping or public app API v3 event constants.
- Preserve bionic text and paragraph-gap preferences when saving unrelated settings cards.

The official installer includes CP210x driver and bootloader-connection troubleshooting. Contributor formatting rules and the layered validation strategy are documented.

Choose the V1.1 or V1.2 build for your PCB. EN/ES/FR specify the initial language only; every image contains all eleven languages. Release archives include English instructions, source provenance, SHA-256 checksums and the existing bookmark rollback guidance.
