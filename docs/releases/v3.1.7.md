Pala One v3.1.7 adds optional bookmark removal on the reader and improves bookmark consistency across reader and browser views.

- Enable bookmark-action toggling in browser settings or through the companion `bookmarkToggle` preference. It is off by default, so existing bookmark gestures remain add-only.
- With toggling enabled, repeat the bookmark action to remove a unique mark on the displayed page. Canonical byte offsets survive font/layout changes; legacy marks retain their page-hint fallback. Multiple matches are preserved instead of guessing which mark to delete.
- Verify stored bookmark records and exact persisted bytes before reporting a successful change. Reading progress and other metadata are retained.
- Browser delete forms identify the book key, page and canonical offset. Stale or older numeric-only forms are rejected and must be refreshed before deletion.
- Browser bookmark labels and exports use decompressed PBT text and stored canonical positions, including wide page labels.
- Preserve valid custom app values in browser dropdowns instead of silently selecting the first preset. Shared form controls keep these changes within the existing OTA slot.

All eleven runtime languages, both board revisions, the public app API v3 and the existing partition and bookmark formats are retained. Choose V1.1 or V1.2 for your PCB; EN/ES/FR specify the initial language only. Release archives include English instructions, source provenance, SHA-256 checksums and rollback guidance.
