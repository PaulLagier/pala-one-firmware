Pala One v3.1.3 is a maintenance update for the shared eleven-language firmware.

- Browser book uploads reject an existing destination with HTTP 409. This includes names that collide after sanitization or shortening. Rename the incoming file or explicitly remove the old book before replacing it. Rejected uploads preserve the existing book and its reading metadata.
- Custom lock controls unlock only with a gesture assigned to Lock device, including after wake and during storage recovery. Legacy controls and automatic locking without an assigned lock gesture retain the hold fallback.
- Failed Wi-Fi association reports a connection failure while leaving setup available for retry. Failed credentials do not replace saved credentials. This corrects the misleading radio-disabled state; it does not claim every reported network incompatibility is resolved.
- The existing screensaver image editor is served as a compressed, content-hashed browser asset. All eleven localized interfaces remain available.

Choose the V1.1 or V1.2 package matching your PCB. EN/ES/FR are initial defaults only; every image includes all eleven languages. The application/storage partition layout is unchanged. Each package includes English instructions and SHA-256 checksums, with exact source provenance in release.json.

Ordinary bookmarks remain V2; wide bookmarks beyond page 65535 use V3. Back up content before rolling back to incompatible firmware. Hardware-specific freeze, charging and Wi-Fi reports remain open unless their individual cause is established.
